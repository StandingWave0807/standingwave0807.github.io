连本机服务

这个页面不存 GitHub 凭据。写操作全部交给你自己电脑上的 sitekeeper，口令只在浏览器本地。

服务没开的话：双击 sitekeeper\start.cmd。

没连上的时候整页是禁用的：字段读不了、发布点不动。真正的把关在本机服务那边——没有口令它一律回 401，路径也只认白名单那几个文件。
