连本机服务

这个页面不存 GitHub 凭据。写操作全部交给你自己电脑上的 sitekeeper，口令只在浏览器本地。

服务没开的话：Windows 双击 sitekeeper\start.cmd；Mac / Linux 在终端里跑 python sitekeeper/keeper.py。口令存过一次，服务开着就会自动连上。

没连上的时候整页是禁用的：字段读不了、发布点不动。真正的把关在本机服务那边——没有口令它一律回 401，路径也只认白名单那几个文件。

所有人打开首页看到的都是这一个。谁在这台电脑上自己调过，他自己那个仍然算， 直到你发布一个新的。

动作

发布就是让本机服务改文件、重建页面、提交并推送；GitHub 的钥匙只在这台电脑上。快捷键：Ctrl+S 存草稿，Ctrl+Enter 发布，Ctrl+M 写公式（光标在公式里就是改它；预览里点公式也能改），Ctrl+F 查找、Ctrl+H 替换，Ctrl+B / I / K 加粗、斜体、链接，Ctrl+. 专注模式，/ 搜笔记。图片直接粘贴或拖进正文就会上传。
